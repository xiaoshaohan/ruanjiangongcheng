# 共享数据库接入说明

本项目的数据库放在一台机器上（下称"主机"），其他电脑不改代码，只改 `backend/.env` 里的连接参数，就连同一份数据。

## 1. 连接参数

| 项 | 值 |
| --- | --- |
| 主机地址 | `10.100.113.166`（主机在校园网内的 IPv4，换网络后会变，届时重新核对） |
| 端口 | `3306` |
| 数据库名 | `student_portrait` |
| 账号 | `sp_app` |
| 密码 | 向组长索取，不要写进任何提交到 Git 的文件 |

主机侧已做的配置：MySQL 服务设为开机自动启动、电源计划关闭了空闲睡眠、建了 `sp_app` 远程账号并授权到 `student_portrait`。

## 2. 组员机器改配置

打开 `backend/.env`，改成：

```
DB_HOST=10.100.113.166
DB_PORT=3306
DB_USER=sp_app
DB_PASSWORD=向组长索取的密码
DB_NAME=student_portrait
PORT=3000
```

改完重启后端。控制台出现"数据库连接成功"即接入成功，页面里看到的学生数应与主机一致（当前 102 人）。

## 3. 先验证网络，再看应用

连不上时按顺序排查，不要一上来就怀疑代码。

```powershell
# 1) 网络与端口是否可达，TcpTestSucceeded 必须为 True
Test-NetConnection 10.100.113.166 -Port 3306

# 2) 账号密码是否正确
mysql -h 10.100.113.166 -P 3306 -u sp_app -p student_portrait -e "SELECT COUNT(*) FROM student;"
```

常见报错的含义：

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `ERROR 2003` / 连接超时 | 主机没开机、不在同一网络、主机防火墙没放行 3306 | 先 `ping` 主机；确认主机已加 3306 入站规则 |
| `ERROR 1045 Access denied` | 密码错，或用了 `root` 账号 | 用 `sp_app` 和约定的密码，不要用 root 远程登录 |
| `ERROR 1130 Host ... is not allowed` | 主机上只允许 localhost 登录 | 主机侧确认 `sp_app` 账号的 host 是 `%` |
| `ERROR 1049 Unknown database` | 数据库名写错 | `DB_NAME` 必须是 `student_portrait` |

## 4. 主机侧需要保证的事

- MySQL 服务处于运行状态且启动类型为自动（`Get-Service *mysql*`）；
- 系统不进入睡眠，或至少接电源时不睡眠（`powercfg /query SCHEME_CURRENT SUB_SLEEP STANDBYIDLE`，交流电源索引为 `0x0` 即从不睡眠）；
- Windows 防火墙放行 TCP 3306 入站（需管理员权限）：

```powershell
New-NetFirewallRule -DisplayName "MySQL 3306 (shared)" -Direction Inbound -Protocol TCP -LocalPort 3306 -Action Allow -Profile Any
```

- 校园网常开 AP 隔离，同网段两台机器也可能互相 ping 不通。此时换同一个路由器 / 手机热点，或改用云数据库。

## 5. 安全边界

- 这套配置只适合课程实验和局域网演示：账号允许任意来源（`%`）、库内是虚构数据。
- 不要把 3306 映射到公网，不要在学生宿舍路由器上做端口转发。
- 密码只放在各人本地的 `.env`，`.env` 已在 `.gitignore` 中，不要改成 `git add -f` 强行提交。
- 主机换 WiFi 或重启后 IP 可能变化，组员连不上时先在主机执行 `ipconfig` 看新的 WLAN 地址。

## 测试边界

- 自动化接口测试使用内存替身，不能证明真实 SQL 与事务行为；真实库验证靠手工用例覆盖。
- 未覆盖并发写入、数据库不可达、超大 CSV（单次上限 5000 行）等异常场景。
- 科研计分系数（10/6/3）与职业推荐前两条阈值是否按新量纲调整，仍待组内讨论，当前沿用原值；现有数据按最新批次统计为“学业基础方向”97 人、“学术研究方向”4 人、“基础积累方向”1 人、“工程实践方向”0 人。兜底文案已改为按得分率指出短板，不再统一表述为“发展均衡”。
- 推荐历史保留策略暂定每学生最多 5 批，未最终拍板。

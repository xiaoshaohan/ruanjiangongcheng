# 核心功能测试记录

测试日期：2026-11-14。测试对象：项目 main 分支提交 `bca3a31` 及本次新增的测试文件。测试数据均为虚构数据。

## 测试方案

采用自动化测试和手工测试结合的方式。自动化测试通过 Node.js 自带的 `node:test` 执行：原有画像单元测试使用模拟数据库连接；本次新增接口测试启动本地临时 HTTP 服务，并使用内存替身代替数据库。替身不能证明真实 MySQL 查询和数据持久化正确。

手工测试在 Windows、Node.js 24.22.0、MySQL 8.0.29 下进行，使用单独的测试数据库和本地服务。接口检查使用 HTTP 请求；页面检查使用浏览器。以下记录的测试人员为项目成员与 Codex 辅助完成，正式报告中的人员信息应按实际参与情况填写。

## 待讨论和测试边界

- 当前学业能力是学分加权平均成绩乘以 0.25，最高为 25；科研和实践各以 100 封顶。再按 40%、30%、30% 加权，理论最高总分为 70。代码注释称学业分满分 100；建议组内确认分数范围与规则，再决定是否调整。上述测试是按现有规则核对结果，不代表规则已经得到业务确认。
- 本轮未覆盖所有页面、数据库异常、多用户并发或部署环境；自动化接口测试使用模拟数据库。科研、实践录入在 M2 中通过接口测试，未分别从页面录入。
- 本项目测试和文档整理使用 Codex 辅助；小组在最终实验报告中应按实际情况记录工具、用途、人工审查、修改及验证过程。

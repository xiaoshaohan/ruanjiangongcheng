# v1.9 测试报告修复对照表

对应输入：`高校学生成长与职业发展数据中台-测试问题报告.docx`，共 54 项（阻断 6、严重 21、一般 19、轻微 8）。
本表逐条列出修复方式与结果，"部分"表示报告建议里的可选项或受环境限制未做，已在备注中写明。

## 一、阻断级（6 项，必须上线前关闭）

| 编号 | 问题 | 修复内容 | 结果 |
| --- | --- | --- | --- |
| R01 | JWT 密钥回退到硬编码值，可伪造任意角色 token | `utils/auth.js` 去掉内置默认密钥：`JWT_SECRET` 缺失或短于 32 字符时进程直接退出；签发时写入 `tv`、`jti`、issuer/audience；`authRequired` 校验后回查 `sys_user`，比对 `status` 与 `token_version` | 已修复 |
| R02 | 公开注册不校验姓名，可冒充教师或学生 | 学生注册必须"学号 + 姓名"与名单完全一致；教师自助注册返回 403，只能由管理员开通；`identity` 缺失或非法返回 400；注册按 IP 每小时限 10 次 | 已修复 |
| R03 | 禁用、删除、改角色后旧 token 仍然有效 | 引入 `sys_user.token_version`：改密码、改角色/状态、重置密码、删除学生解绑账号都会递增版本；每次请求比对 token 里的 `tv`，不一致返回 401 | 已修复 |
| R04 | 编辑学生时未提交的电话和邮箱被写成 NULL | `PUT /api/students/:id` 改为部分更新，只对请求体里出现的字段生成 SET 子句 | 已修复 |
| R05 | 批量导入绕过校验，产生 127.52% 等异常画像 | 导入改为逐行校验（分数范围、学分、日期、年级、性别、长度），非法行不入库并返回行号原因；导入完成后对涉及学生重算画像 | 已修复 |
| R06 | 导入学生时用空值覆盖未提供的字段 | 导入只更新 CSV 中实际出现的非空列，空列不再覆盖原值；SQL 列清单按表头动态生成 | 已修复 |

## 五、验证方式

1. 单元测试：`cd backend && npm test`，31 项全部通过（画像算法 10 项、接口与权限 21 项）。
2. 数据库迁移：`source sql/migrate-v1.9-hardening.sql`，核对查询显示 0 组重复数据、102 名学生有性别值、三个唯一索引建成、`ability_profile.config_snapshot` 列存在。
3. 浏览器走查（718×667 与桌面视口）：管理员登录、学生分页/搜索/性别显示、导入模板下载、删除影响弹窗、画像分母与待重算标记、看板学期口径提示、设置开关文案、教师档案状态列、教师端编辑字段限制与录入下拉范围、注册页学号/姓名核验。
4. 接口回归：JWT 伪造、旧 token 撤销、越权提交、重复导入、GBK 文件、导出筛选、审计查询等按报告证据逐项复测。
